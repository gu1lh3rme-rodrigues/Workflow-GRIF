# Workflow-GRIF
Utilização do projeto Workflow para as atividades do GRIF Registro, assim como possíveis melhorias para o programa a parte do original; Todos os direitos a parte da Dev4Tech


A utilização desse programa irá ocorrer como um meio de auxilio e teste prático do programa para fins educativos e como maneira de avaliar o desempenho do programa em um uso de escala maior, sendo pretendido ampliar esse uso até para os alunos do IF se ocorrer a concordância da equipe Dev4Tech
